## 四、各项目详细优劣势

### S 级

**cortex（本地 NotebookLM 替代）**
- 优：摄入(PDF/PPTX/DOCX/网页/YouTube/录音/OCR)→生成(闪卡/测验/考试/cheatsheet)→复习(FSRS+Anki互操作)→分析 全闭环；引用问答（混合检索+内联引用）质量高；版本化 SQLite schema 是优秀范式
- 劣：Rust/Tauri 门槛高；本地优先无多人协作；AI 成本依赖用户自配 key

**OpenTutor（积木式自适应学习）**
- 优：MIT 协议 + local-first；FSRS 4.5 + BKT/知识图谱/认知负荷等学习科学支撑；混合 BM25+向量 RAG；多 LLM 熔断路由；3 专家代理
- 劣：仍公测单用户；移动端未完善；依赖本地硬件

### A 级

**Incrementum（增量阅读 + SRS）**
- 优：多调度算法（FSRS-6/SM-18/SM-20/SM-2）全开源最全；增量阅读工作流；音视频转录+OCR 完整；Rust 高性能
- 劣：构建门槛高（Rust+whisper.cpp）；体量大

**compass（自托管 FSRS-6 刷题）**
- 优：FSRS-6 实现规范（评分/两阶段提交/不可变 ReviewLog）；导入解析健壮（MD/Excel/Word、中文别名、题型推断）；MIT + 自托管无锁定
- 劣：AI 生成仅 topic→题目基础版；无闪卡形态；上传依赖本地磁盘

**LearnKit（Obsidian FSRS-6 插件）**
- 优：FSRS-6 专业（个性化参数优化、状态迁移、fuzz）；引擎/平台分层清晰可移植；Anki 互操作；AI BYOK 可选
- 劣：强绑 Obsidian 非独立产品；WASM SQLite+React 较重

**PageLM（NotebookLM 开源版）**
- 优：多 LLM 提供商抽象成熟；LangChain/LangGraph 代理架构清晰；文档→测验/闪卡/笔记/播客多形态
- 劣：社区许可非 OSI（商用受限）；默认 JSON 存储；SRS 算法薄弱

### B 级

**flashcards-open-source-app**
- 优：FSRS 文档化 + 离线优先同步（outbox+幂等）；数据建模规范（UUID/ULID+墓碑删除+追加式复习历史）；MCP/Agent API 开放
- 劣：强绑 AWS 本地难跑；无 PDF 生成题库；复杂度偏高

**NitroAI**
- 优：真正 local-first（自动管理 Ollama 生命周期）+ 无遥测无账号；纯函数调度器易测试
- 劣：AGPL-3.0；作者明示「起点非成品」；无同步多端

**uxie**
- 优：双端架构（Web+Electron）复用 shared 层；PDF 高亮/笔记/TTS/OCR 体验细腻；sqlite-vec+BYOK 隐私好
- 劣：依赖大量付费第三方；无 SRS/错题本；无 License

**AnkiBase**
- 优：复用 Anki 成熟 SRS 与卡组生态（兼容性最好）；每用户独立容器多租户；AI provider 抽象+多回退
- 劣：依赖 headless-anki Docker 部署维护成本高；AI 仅词汇；后端 2000+ 行 main.py

### C 级

**Shiori-v1**：功能面广（测验/闪卡/成绩/计划/排行榜）但浅，逻辑全在前端，无真 SRS。
**StudyFlow**：Redis 队列解耦 + 429 熔断退避健壮，但 api 单文件、无文档导入无 SRS、无测试。
**scholarsome**：Anki/Quizlet/CSV 双向导入 + 企业级工程规范，但无 AI 无 SRS，MySQL 较重。
**memoet**：SM-2 用 Rust NIF 高性能实现值得借鉴，但无 AI、Elixir 学习成本高、年代早。
**mianshiya**：完整产品闭环（题目+题解+试卷+社区+管理后台）+ ES 多维检索，但技术栈老旧、强绑腾讯云、与学习定位无关。

## 五、对 agent-quiz（EStudy）的启示

### 5.1 我们的差异化优势（应保持强化）

1. **真正的多 Agent 编排是护城河**：Navigator/Orchestrator/Document/Knowledge/Question/Review 六 Agent + LangGraph 状态管理，是全部 15 个竞品中唯一做到「Agent 与业务代码严格分离 + 结构化 State 传递 + 三层校验 + Review 回环」的。PageLM 虽有 LangGraph 但粒度粗，其余多为单次 LLM 调用。
2. **完整学习闭环**：`资料导入→知识提取→思维导图→RAG→出题→审题→刷题→错题→统计` 端到端打通，cortex/OpenTutor 之外无人做到。
3. **工程规范严谨**：12 表 ORM 唯一真相源、168 后端测试、三层校验、软删除 + RESTRICT 历史保护，远超多数「演示级」竞品。

### 5.2 必须补齐的短板（按优先级）

|  优先级   | 事项                                                                                                                      | 参考项目                         |
| :----: | ----------------------------------------------------------------------------------------------------------------------- | ---------------------------- |
| **P0** | **SM-2 → FSRS 升级**：主流已全面转向 FSRS-6（OpenTutor/LearnKit/compass/Incrementum/cortex）。SM-2 是 1980 年代算法，FSRS 预测准确率显著更高且参数可个性化 | compass、LearnKit（ts-fsrs 移植） |
| **P0** | **LangGraph checkpoint 持久化**：当前内存态，生产重启即丢；参考 OpenTutor/PageLM 的持久化状态机                                                   | OpenTutor                    |
| **P1** | **MCP / 工具扩展接口**：flashcards-app、Incrementum、PageLM 均暴露 MCP/Agent API。我们应开放「自定义工具」扩展点，契合「LLM Agent 自定义工具扩展」卖点            | flashcards-app、PageLM        |
| **P1** | **local-first / BYOK 双模式**：NitroAI/OpenTutor/cortex/AnkiBase 都强调本地优先 + 用户自带 key。可降低部署门槛并增强隐私卖点                          | NitroAI、cortex               |
| **P1** | **图片/多模态解析**：当前图片解析后置；cortex/Incrementum/uxie 已支持 OCR/音视频。接入千问视觉后对齐                                                     | cortex、Incrementum           |
| **P2** | **FSRS 数据模型范式**：compass 的不可变 ReviewLog + 两阶段提交、flashcards-app 的 outbox 同步、cortex 的版本化 SQLite schema，都值得引入               | compass、cortex               |
| **P2** | **Docker 一键部署 + 宽松协议**：若开源，建议 MIT（避开 AGPL 竞品的商用障碍）+ docker-compose 自托管，对齐 OpenTutor/compass/cortex                      | OpenTutor、compass            |

### 5.3 战略建议

1. **对标 OpenTutor + compass 的交集**：我们 = OpenTutor 的「多 Agent + local-first + FSRS」+ compass 的「自托管 + 刷题 + 错题」，但多了**真正多 Agent 编排**和**完整闭环**。这是可对外宣传的差异化。
2. **协议选择**：若考虑开源商用，优先 MIT/Apache-2.0。当前竞品中 AGPL 项目（NitroAI/scholarsome/memoet）均非 AI 增强方向，MIT 阵营（OpenTutor/compass/LearnKit/cortex）才是新锐主流，用 MIT 可与他们同台竞争。
3. **优先级排序**：FSRS 升级 > checkpoint 持久化 > MCP 扩展 > local-first > 多模态，先补「算法」和「稳定性」，再补「生态开放」。

## 六、结论

在「文档导入 + AI 生成题库 + 间隔重复复习 + LLM Agent 编排 + 自托管」这一组合定位上：

- **五要素全具备的顶级玩家**：cortex、OpenTutor、Incrementum、compass（后两者 AI 生成较弱）。
- **agent-quiz 的独特身位**：是唯一以「多 Agent 编排」为核心架构的项目，Agent 深度远超竞品；短板集中在 SRS 算法代际（SM-2 vs FSRS）与工程稳定性（checkpoint、部署）。
- **最值得深入阅读源码的 3 个项目**：cortex（闭环完整性 + 数据模型）、compass（FSRS-6 实现 + 刷题形态，与我们最同构）、OpenTutor（学习科学 + 专家代理 + local-first）。
