# 文档一：EStudy 项目需求说明书

## 1. 项目概述

### 1.1 项目名称

**EStudy——智能题库与学习系统**

### 1.2 项目定位

EStudy 面向大学生，尤其针对**大学课程期末复习场景**，通过 AI Agent 将学生已有的课程提纲、课件、教材等学习资料自动转化为结构化学习资源。

系统核心目标是：

> **上传学习资料，自动生成知识结构、思维导图和针对性题库，并通过刷题和错题记录形成学习闭环。**

项目原规划中将产品概括为“丢资料进去，出学习系统出来”，核心能力包括从用户资料生成题库、思维导图等学习资源。

---

## 2. 用户需求

### 2.1 目标用户

主要用户为：

> **大学生**

重点使用场景：

> **期末考试复习**

学生通常已经拥有教师提供的：

- 课程提纲
    
- PPT
    
- PDF
    
- Word 文档
    
- 复习资料
    

但缺少：

- 系统化知识结构
    
- 思维导图
    
- 针对资料的题库
    
- 对知识掌握程度的反馈
    

原项目需求分析中将这些问题概括为“有提纲但没有题库”“有提纲但没有思维导图”“错题不会归纳”等痛点。

---

# 3. 核心需求

## 3.1 学习资料导入

用户能够上传课程学习资料。

第一阶段重点支持：

- PDF
    
- Markdown
    

后续扩展：

- Word
    
- PPT
    
- 图片
    
- 网页
    

系统将资料统一转换为结构化内容，为后续 Agent 使用。

原规划中已将“PDF/Word/PPT/图片 → 结构化 .md”和章节、知识点提取列为 P0。

---

## 3.2 自动知识整理

用户上传资料后，系统自动：

```text
资料
 ↓
文档解析
 ↓
章节识别
 ↓
知识点提取
 ↓
知识结构
```

用户无需手动整理章节和知识点。

---

## 3.3 自动生成思维导图 ★ P0

这是第一阶段核心功能。

资料解析完成后：

```text
课程资料
    ↓
知识点提取
    ↓
建立章节层级
    ↓
自动生成思维导图
```

用户可以查看课程整体知识结构。

原项目规划也已经将“思维导图自动生成”列为 P0 核心链路。

---

## 3.4 AI 自动出题 ★ P0

系统根据用户上传的课程资料和知识点自动生成题目。

第一阶段支持：

- 单选题
    
- 多选题
    
- 填空题
    
- 简答题
    

用户可以根据章节、知识点、题型和数量进行生成。

项目原规划已确定四种基础题型，并将 AI 从资料批量出题列为 P0。

---

## 3.5 AI 自动审题 ★ P0

生成题目后，由独立的审核 Agent 对题目进行检查：

```text
Question Agent
      ↓
生成题目
      ↓
Review Agent
      ↓
审核
  ↙       ↘
通过      不通过
 ↓          ↓
题库      重新生成
```

主要检查：

- 答案正确性
    
- 题目与知识点匹配程度
    
- 题目是否存在歧义
    
- 题目质量
    
- 选项合理性
    

项目原设计采用“出题 → 审核 → 退回修改 → 再审核”的提议者—审核者模式。

---

# 4. Navigator Agent ★ 新增核心设计

EStudy 增加一个**总导航 Agent**，作为用户与 Agent 系统之间的统一智能入口。

### 主要职责

#### ① 功能指导

用户可以直接询问：

> “我怎么生成题目？”

Navigator Agent 为用户说明操作方式。

#### ② 用户意图理解

例如：

> “帮我把这个 PDF 整理成知识点。”

系统自动判断用户需要执行资料解析和知识整理任务。

#### ③ 任务规划

例如：

> “帮我整理这份资料，然后生成 20 道选择题。”

Navigator Agent 将任务拆解为：

```text
解析资料
 ↓
提取知识点
 ↓
生成思维导图
 ↓
生成题目
 ↓
审核题目
```

#### ④ Agent 调度

Navigator Agent 不负责具体完成专业任务，而是调用对应的专业 Agent。

```text
                用户
                 ↓
         Navigator Agent
                 ↓
          任务理解/规划
                 ↓
        Agent Orchestrator
                 ↓
       ┌─────────┼─────────┐
       ↓         ↓         ↓
    Document  Question   Review
      Agent     Agent     Agent
```

---

# 5. 刷题与错题

系统提供：

- 自由练习
    
- 普通练习
    
- 模拟考试
    
- 按章节刷题
    
- 按收藏刷题
    
- 错题自动记录
    

现有项目已经具备多种刷题模式、SM-2 间隔重复以及错题自动收集等基础能力。

---

# 6. P0 功能范围

最终确定第一阶段：

```text
┌───────────────────────────────┐
│             P0                │
├───────────────────────────────┤
│ ① 资料导入                    │
│ ② 文档解析                    │
│ ③ 知识点提取                  │
│ ④ 自动生成思维导图            │
│ ⑤ AI自动出题                  │
│ ⑥ AI自动审题                  │
│ ⑦ 题库管理                    │
│ ⑧ 刷题                        │
│ ⑨ 错题记录                    │
│ ⑩ Navigator Agent             │
└───────────────────────────────┘
```

原规划的 P0 也主要集中在资料解析、AI 出题、AI 审核、思维导图、错题本和搜索等核心链路。

### P0 实现进度（截至当前）

| P0 项 | 状态 | 说明 |
|---|---|---|
| ① 资料导入 | ✅ | 上传/列表/删除/重建向量索引 + 实时进度 |
| ② 文档解析 | ✅ | PDF/Word/PPT/Markdown/TXT/HTML；图片解析为 P1（千问视觉）|
| ③ 知识点提取 | 🟡 | 确定性 `import_sections` 建树；Knowledge Agent（LLM 语义提取）为 P1 |
| ④ 自动生成思维导图 | ✅ | markmap 渲染知识树 |
| ⑤ AI 自动出题 | ✅ | 生成 + 三层校验（需配置 `DEEPSEEK_API_KEY`）|
| ⑥ AI 自动审题 | ✅ | Review Agent |
| ⑦ 题库管理 | ✅ | CRUD / 软删除 / 收藏 / 举一反三 / 搜索 / 批量删除 |
| ⑧ 刷题 | ✅ | 宽松/普通/严格三模式 + 自动判题 + SM-2 |
| ⑨ 错题记录 | ✅ | 答错生成 / 编辑错因 / 筛选 / 收藏 |
| ⑩ Navigator Agent | 🟡 | Navigator/Orchestrator/Question/Review 独立节点已实现；Document/Knowledge 语义化后置 |

# 文档二：EStudy 用例分析

## 1. 系统参与者

### 学生

系统主要使用者。

负责：

- 上传资料
    
- 查看知识结构
    
- 查看思维导图
    
- 使用 AI 助手
    
- 查看题库
    
- 刷题

# 2. Navigator Agent 任务调度流程

这是你们后面 Agent 系统的核心流程，可以单独放一张图。

```text
                    用户
                     │
                     ▼
             Navigator Agent
                     │
                     ▼
                 理解意图
                     │
                     ▼
                 判断任务
                     │
             ┌───────┼────────┐
             ▼       ▼        ▼
          资料处理  出题任务  学习咨询
             │       │        │
             ▼       ▼        ▼
         Document  Question  直接回答/
           Agent     Agent     调用其他Agent
             │       │
             └───┬───┘
                 ▼
             Review Agent
                 │
                 ▼
              任务结果
                 │
                 ▼
          Navigator Agent
                 │
                 ▼
                用户
```

这里要特别注意：

> **Navigator Agent 是“总入口”，不是“万能 Agent”。**

它负责理解和调度；专业 Agent 负责具体工作。
