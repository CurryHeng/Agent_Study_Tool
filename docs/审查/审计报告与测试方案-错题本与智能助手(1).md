## §3 场景 A：刷题（做题过程中）

> 页面：首页卡片"刷题复习"进入 `/review`。三种模式：宽松（不限时）/ 普通（逐题计时）/ 严格（答完即判）。

### 🔴 A1 严格模式做简答题会"卡死"　【P1 · F1 · ✅实测必现】
- **现象**：严格模式下做到简答题：写完答案 → 点"揭晓答案" → 点"我做对了/我做错了"之后，页面**什么反应都没有**——没有提交按钮、进度条不动、无任何提示。
- **影响**：这道题的作答**不会保存**（后端无任何记录），错题本也找不到它；只能点"下一题"跳过，进度永远差一题。
- **怎么点出来**：刷题页 → 选"严格模式" → 开始 → 做到一道简答题 → 作答 → 揭晓答案 → 自评 → 观察。
- **实测记录**：Playwright 真实点击复现——自评后提交按钮=0、无"已记录"提示，页面卡在无反馈状态（截图 `09-review-strict-short.png`）。
- **应该怎样**：自评后自动判分并记录，或出现提交按钮。

### 🔴 A2 简答自评"我做错了"，错题本却没有这条　【P1 · B3（后端）· ⚠️条件性缺陷】
- **现象**：宽松模式做简答题 → 揭晓答案 → 自评"我做错了"，然后去错题本一看——**没有这条记录**。
- **影响**：用户以为错题被记了，复习时漏掉（学习闭环断裂）。
- **实测记录**：本机 LLM 已配置 → 判分正常（is_correct=false → 错题正常入本），**未触发**。该缺陷仅在 **LLM 不可用/判分失败**（返回 None）时发生：`review_service` 只认 `is_correct is False`，None 不写错题本。代码路径确认存在，需在无 key 环境复验。
- **怎么点出来**：不配 LLM key（或让判分失败）→ 简答 → 自评"我做错了" → 查错题本。
- **应该怎样**：用户自评"做错了"（rating=again/hard）就该进错题本，不依赖 AI 判分结果。

### 🟡 A3 提交评分时点"下一题"，结果串到下一题　【P2 · F26】
- **现象**：点完评分按钮（忘记/困难/正确/简单）后**马上**点"下一题"（网络慢时更容易），上一题的对错结果会显示在**下一题的卡片**上，进度统计记错位置。
- **应该怎样**：提交期间锁定上一题/下一题按钮。

### 🟡 A4 答错后不点评分直接"下一题"，这道题等于白做　【P2 · F28】
- **现象**：选择题答错，页面显示"回答错误"后，不点四个评分按钮直接点"下一题"——这道题**不生成任何记录**，不进错题本，且**没有任何提醒**。
- **应该怎样**：跳过未评分的题时弹提示（"放弃记录这道题？"），或答错自动按最低掌握度记录。

### 🟡 A5 错因表单的"你的错误答案或过程"填了也白填　【P2 · F27】
- **现象**：答错弹出的表单有两个输入框，第一个"你的错误答案或过程"填完后保存——内容**哪儿都找不到**（后端没存这个字段）。
- **应该怎样**：真正保存该字段，或直接删掉这个输入框。

### 🟡 A6 普通模式倒计时到 0，什么都没发生　【P2 · F11】
- **现象**：普通模式每题 5 分钟倒计时，归零后不自动交卷、无超时提示，计时器形同虚设。
- **应该怎样**：到 0 自动提交当前答案，或弹提示。

### 🟡 A7 断网时提交/评分，页面毫无反应　【P2 · F7】
- **现象**：断网点提交或评分，页面既不变也不报错，用户不知道发生了什么。
- **应该怎样**：错误提示 + 重试。

### 🟡 A8 "举一反三"的题只能看，不能做　【P2 · F10】
- **现象**：评级后点"举一反三"，生成的变式题只显示题干和答案，没有"练习这道题"或"收藏"按钮。
- **应该怎样**：变式题可直接进入练习，或一键入库。

### 🟡 A9 完成页看不到错题明细　【P2 · F9】
- **现象**：一轮复习完成，结果页只有掌握率百分比，看不到"哪几道做错了"，也没有"去错题本"按钮。
- **应该怎样**：结果页列出答错题目 + 一键跳错题本。

### 🟡 A10 中途退出再继续，进度可能错位　【P2 · F8】
- **现象**：答到一半刷新页面，点"继续刷题"——如果这期间到期列表变了（例如又做了别的题），恢复的进度和题目可能对不上。
- **应该怎样**：按题目 id 重新对齐恢复。

## §4 场景 B：错题本（复习错题时）

> 页面：侧边栏"错题本"进入 `/wrong`。

### 🔴 B1 保存错因失败时页面卡死　【P1 · F2】
- **现象**：点"标注错因"→ 输入 → 点保存，此时若断网/后端挂了：**无任何提示，编辑框关不掉、按钮点不动**（卡在编辑态，只能刷新页面）。
- **怎么点出来**：错题本点"标注错因"→ 输入 → DevTools 断网/停后端 → 点保存 → 观察。
- **应该怎样**：失败时退出编辑态并提示"保存失败，请重试"。

### 🔴 B2 错题无法"标记已掌握/移除"　【P1 缺功能 · F19/G1】
- **现象**：同一道题重新做对了，它**还躺在错题本里**；页面上没有任何"已掌握""移除"按钮，错题本只增不减。
- **影响**：错题本越积越乱，用户无法管理复习进度——这是错题本闭环缺失的关键一环。
- **应该怎样**：每条错题加"已掌握/移除"按钮（后端配套删除接口）。

### 🔴 B3 没有"错题专练"　【P1 缺功能 · F20/G5】
- **现象**：想集中重刷错题，只能一条一条点"重做此题"，且每道题都要重新选模式点开始。
- **应该怎样**：错题本顶部加"开始错题重练"按钮，一次批量刷全部错题。

### 🟡 B4 断网进错题本/翻页，静默失败　【P2 · F29】
- **现象**：后端挂掉时进入错题本或翻页，页面空白/不动，无任何提示。
- **应该怎样**：错误提示 + 重试按钮。

### 🟡 B5 错题不能搜索、不能按错因筛选　【P2 缺功能 · F18/G6】
- **现象**：不能搜错题，不能按错因类型（概念不清/计算失误…）筛选，不能按日期筛选。
- **应该怎样**：加搜索框 + 错因/日期筛选；统计页的"错因分类分析"也应可点击钻取到错题本。

### 🟡 B6 时间显示的是"第一次答错"的时间　【P2 · B7（后端）】
- **现象**：同一道题第二次又答错了，错题本显示的日期还是**第一次**答错的日期，看不出"最近又错了"。
- **应该怎样**：显示最近一次答错时间。

### 🟡 B7 分页不友好　【P2 · F23】
- **现象**：每页固定 10 条，没有页码跳转、不能改每页条数，错题多时翻页很累。
- **应该怎样**：页码跳转 + 每页条数选择。

## §5 场景 C：智能助手（聊天过程中）

> 页面：侧边栏"智能助手"或右下角悬浮球进入 `/assistant`。

### 🔴 C1 发送消息时切换会话，回复串到另一个会话　【P1 · F24】
- **现象**：在会话 A 发了消息，等回复时点开会话 B——**A 的回复会出现在 B 的消息列表里，而且页面被强行切回 A**。
- **影响**：多轮对话内容错乱，演示时点一下就会翻车。
- **怎么点出来**：会话 A 发消息 → 等待回复时点会话 B → 观察回复出现在哪里。
- **应该怎样**：切换会话时锁定/丢弃在途请求，回复按发起时的会话归属。

### 🔴 C2 重新打开历史会话，所有提案都显示"已确认"　【P1 · F3/B4】
- **现象**：聊天里点过"确认执行"的提案，刷新页面重新打开这个会话，**所有提案卡片都显示"已确认"**——包括当时点过"取消"的、甚至从未确认过的。
- **影响**：用户误以为操作都执行了（实际可能没执行），也失去了补确认的机会。
- **怎么点出来**：确认一条提案 → 刷新页面 → 重新点开该会话 → 看提案状态。
- **应该怎样**：确认结果实时写回；历史会话如实显示每条提案的真实状态。

### 🔴 C3 删除会话没有确认弹窗　【P1 · F4】
- **现象**：会话列表点小垃圾桶图标，整个会话（全部聊天记录）**立刻被删**，无二次确认，删了找不回。
- **应该怎样**：加"确定删除该会话？"确认框。

### 🔴 C4 建议语"我哪里比较薄弱？/今天该复习什么？"是空话　【P1 缺功能 · F6/G2 · ✅实测（比空话更糟：事实性错误）】
- **现象**：点页面自带的这两个建议语，AI **没有调用任何工具**（展开"执行步骤"为空），只是凭空编一段文字，数据不来自你的真实学习记录。
- **实测记录**：本机真实点击"我哪里比较薄弱？"——助手调用了 get_questions/get_knowledge_tree 工具（4 步），却回复**"当前系统里没有你的作答记录"**；而实际数据库里有 13 条答错记录。助手因缺少 `get_stats`/`get_due` 等工具，**给出了与事实相反的结论**，会直接误导用户。
- **应该怎样**：给 Agent 补齐"统计/到期复习"工具；未补前先换掉这两个建议语。

### 🔴 C14 多轮出题请求不再调用工具（"再来 2 道"变空头支票）　【P1 新发现 · ✅实测】
- **现象**：在同一个会话里先让 AI 出题（正常生成提案），确认后再发"再帮我出 2 道判断题"——AI 只**口头回复"我会沿用主题再生成"**，实际没有调用出题工具（steps=0、proposals=[]），一道题都没生成，也没有任何提示告知"没做"。
- **影响**：Day5 验收脚本有"再来 5 道难的"场景，实测这种多轮续出题**不执行**，演示必翻车。
- **怎么点出来**：助手发"帮我出 3 道单选题"→ 确认 → 再发"再帮我出 2 道判断题" → 观察无提案卡、无入库。
- **应该怎样**：强化 system prompt 对多轮任务的工具强制约束（延续上一轮主题时必须调用工具），或对"出题/生成"类意图做路由兜底。

### 🔴 C5 说"把这里改简单点"，AI 不知道"这里"是哪　【P1 缺功能 · F5/G3】
- **现象**：先在导图/题库看了某个知识点，再打开助手说"把这里改简单点"，AI **完全不知道"这里"指什么**。
- **影响**：多轮指代功能（契约 #41）名存实亡。
- **应该怎样**：各页面加"问 AI"入口，把当前选中的知识点/题目带过去；助手页显示"当前上下文"徽标。

### 🟡 C6 确认卡片上显示一大段乱码　【P2 · F25】
- **现象**：让 AI 出题后，确认卡片"变更内容"显示一大段转义 JSON（`{"questions":[{"type":...`），完全不可读。
- **应该怎样**：改成"将新增 5 道审核通过的题目"这类人话摘要。

### 🟡 C7 确认执行后看不到执行结果　【P2 · F15】
- **现象**：点"确认执行"后卡片只变绿，不显示"已入库 5 道题"，用户不确定是否真的成功。
- **应该怎样**：确认后显示执行结果摘要。

### 🟡 C8 提案过期没有倒计时提示　【P2 · F16/B1】
- **现象**：AI 给的提案 10 分钟后过期，页面上毫无提示，点确认才报"提案已过期"；服务重启后提案也会全部丢失。
- **应该怎样**：卡片显示剩余有效时间；提案落库持久化。

### 🟡 C9 消息不能取消、失败不能重发　【P2 · F14/B2】
- **现象**：AI 回复慢时无法中止；前端 120 秒超时后**后端还在继续跑**（浪费额度）；发送失败的消息没有"重发"按钮。
- **应该怎样**：加中止按钮 + 失败重发 + 后端任务可取消。

### 🟡 C10 长会话只能看到最近 50 条　【P2 · F13】
- **现象**：聊天超过 50 条后重新打开会话，只加载最近 50 条，没有"加载更多"。
- **应该怎样**：滚动到底自动加载更早消息。

### 🟡 C11 默认"全部练习册"容易答串　【P2 · F21】
- **现象**：练习册下拉默认"全部练习册"，AI 可能把你的资料和其他练习册内容混在一起回答。
- **应该怎样**：默认选中最近使用的练习册。

### 🟡 C12 手机/窄屏看不到会话列表　【P2 · F12/G13】
- **现象**：窄屏下左侧会话栏直接隐藏，无法切换/新建会话。
- **应该怎样**：抽屉式侧栏。

### 🟡 C13 会话不能重命名；"+"按钮会立即产生空会话　【P2 · F17】
- **应该怎样**：支持重命名；新建会话可延迟到发送首条消息时创建。

## §7 后端审查结论（用户语言版）

> 详细技术分析见 §8 附录。这里只说"对用户意味着什么"。

| # | 对用户意味着什么 | 建议 | 级别 |
|---|---|---|---|
| BE-1 | **服务重启后，所有待确认提案全部丢失**（提案存在内存里）；多进程部署时点确认还可能报"提案不存在" | 提案落库持久化 | P1 |
| BE-2 | **聊天请求同步阻塞**：AI 慢时整条请求占着连接，前端超时后后端还在跑，浪费 token | 长任务异步化（先返回任务号，前端轮询结果） | P1 |
| BE-3 | 简答自评"做错了"不进错题本（见 A2） | 按"again/hard"评分写入错题本 | P1 |
| BE-4 | 提案状态不回写会话记录（C2 的根因） | 确认后更新会话消息里的提案状态 | P1 |
| BE-5 | 错题本列表/筛选在内存里做，错题多时打开会越来越慢；`page_size` 可传超大字面值拖垮接口 | 筛选/分页下沉 SQL + 参数校验 | P2 |
| BE-6 | 连点"AI 错因分析"会重复调 LLM（重复花钱）；分析历史无条数上限 | 节流/缓存 + 历史截断 | P2 |
| BE-7 | 同一题答错多次只保留一条错题记录，且时间还是第一次的（B6） | 记录最近答错时间 | P2 |
| BE-8 | 会话列表逐条查最后消息，会话多了变慢 | 一次查询取回 | P2 |
