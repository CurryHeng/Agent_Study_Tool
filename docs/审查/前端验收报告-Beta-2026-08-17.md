## 问题清单

### [P1-1] 题库默认内置题库隐藏 AI 生成入口
- 页面：题库
- 类型：产品缺失/交互
- 描述：默认选中内置题库时不显示“AI 生成”，用户以为不能 AI 出题。
- 建议：内置题库也显示 AI 生成入口，或提示切换到自己的练习册。

### [P1-2] 文件库自动出题未配置 Key 时静默失败
- 页面：文件库/AI 设置
- 类型：功能
- 描述：勾选“导入后自动生成题目”但未配置 LLM Key 时，无任何提示。
- 建议：后端返回 generation_error，前端展示“未配置 AI Key”提示。

### [P1-3] 文件库上传缺少进度/阶段反馈
- 页面：文件库
- 类型：交互
- 描述：上传大文件只有 spinner，无百分比和解析阶段提示。
- 建议：接入 uploadWithProgress，显示百分比和多阶段文案。

### [P2-1] 首页支持格式文案不一致
- 页面：首页
- 描述：文案仍写“PDF / Word / PPT / Markdown”，未包含 TXT/HTML/图片。

### [P2-2] 缺少独立“知识树/提纲”页面
- 页面：导航/可视化
- 描述：需求提到知识树，但前端没有独立提纲/知识树页。

### [P2-3] 知识图谱节点名称截断
- 页面：知识图谱
- 描述：节点只显示前 8 个字符，无 hover 完整名称。

### [P2-4] 删除等操作使用原生 confirm
- 页面：全站
- 描述：与整体 UI 风格不一致。

### [P2-5] 分页缺少总数/总页数
- 页面：题库/错题本
- 描述：只有第 N 页，无“共 N 条/M 页”。

### [P2-6] 思维导图节点编辑/AI 扩展入口不明确
- 页面：思维导图
- 描述：依赖 #61/#62，普通用户不易发现。

### [P2-7] AI 助手错误提示不在对话流中
- 页面：AI 助手
- 描述：失败显示在顶部横幅，与对话上下文分离。

### [P2-8] 可增加全局 Toast 统一反馈
- 页面：全站
- 描述：当前反馈方式不统一。

### 新增问题

### [P2-9] 文件库允许重复上传同一文件
- 页面：文件库
- 描述：同一份文件可反复上传，列表出现多条同名记录，无去重/覆盖提示。
- 复现：连续上传两次 `ux-test.md`，列表出现两条。
- 建议：按“文件名+大小”或内容 hash 提示“已存在，是否覆盖/跳过”。

### [P2-10] 上传成功提示未区分是否真正生成题目
- 页面：文件库
- 描述：勾选自动出题但未配置有效 Key 时，只显示“上传成功，正在解析…”，用户不知道题目未生成。
- 已对应 P1-2。

### [P2-11] 题库 AI 生成在无有效 Key 时错误反馈不够及时/明确
- 页面：题库
- 描述：点击生成后若 LLM 调用失败，错误提示可能较晚出现或未出现在明显位置；需等待真实环境确认。
- 建议：在生成按钮附近固定显示“未配置 AI Key”预检提示。

### 新增问题

### [P2-12] 空练习册进入“编辑模式”无明确提示
- 页面：题库
- 描述：切换到题目数为 0 的练习册后点击“编辑”，没有题目可勾选，也没有“该练习册暂无题目”的引导。
- 建议：空练习册编辑模式下显示空状态提示，并提供“去添加题目/AI 生成”入口。

### [P2-13] 题库“编辑”按钮对只读/空练习册的可用性不清晰
- 页面：题库
- 描述：内置题库也显示“编辑”按钮，但内置题只读，用户点击后可能困惑。
- 建议：只读练习册隐藏“编辑”，或点击时提示“内置题库只读”。
