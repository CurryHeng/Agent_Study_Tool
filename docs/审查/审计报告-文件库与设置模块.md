## 五、后续接口预留建议

1. **数据管理**：预留 `GET /api/settings/backup`（导出）与 `POST /api/settings/backup/restore`（导入），数据源复用现有 SQLite + Chroma。
2. **自动出题预览**：预留「题目草稿」态（`Question.status=generated` 已有枚举但未使用），供「确认预览入库」复用两阶段确认语义。
3. **上传异步化**：`DocumentStatus.processing` 枚举已预留，可用于后续状态轮询/异步任务，无需改表。
