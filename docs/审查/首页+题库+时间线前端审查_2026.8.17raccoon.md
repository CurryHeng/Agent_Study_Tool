# 首页 + 题库 + 时间线 前端审查（Raccoon）

> 审查日期：2026-08-17  
> 审查人：Raccoon0725

## 首页

1. 首页导入资料基本形同虚设，不知道为什么导入文件那里要默认显示已有题库和导入过的文件，导入过的文件也打不开；应该是像一个工作区那样能够选择文件后看到打开过的文件在某一个区域，并可以有简单快捷方式打开删除，最理想情况是能够打开一个文件夹专门存放这些被向量化储存的文件，移动进去就会自动处理。
2. 首页卡片应该可以个性化摆放，加入一个可以选择自定义放置的卡片，包括顶部状态栏也是一样应该可以在设置那里调整个性化摆放，默认的应该只有几个，其他的默认先放卡片里面，主页应该尽可能简洁一些。
3. 首页的按钮缺少例如待复习、连续天数、错题本数、近30天答题这种能激起用户兴趣的数据。

## 题库

1. 举一反三按钮失常，会返回原题。
2. UI：每道题缺少小标签，多选不明确。

![[Pasted image 20260817203608.png]]

3. 按钮意义不明确：第一行应该不用显示。

![[Pasted image 20260817203608.png]]

4. 选择记忆后应该会高亮表示选中。
5. 错因目前缺少常规选项，详细原因缺少AI拓展，且应该限制字数（好像在错题本中有这一项功能，在刷题界面却缺失了）。
6. 返回上一题会导致所做题丢失。
7. 错因保存后会导致正确答案丢失。
8. 快捷键没有绑定。
9. 正确答案不够明显。

![[Pasted image 20260817204246.png]]
![[Pasted image 20260817204225.png]]

10. 固定做完二十道题才会记录在进度条，而不是根据题号记录。

![[Pasted image 20260817204401.png]]

11. 题库界面的知识点把全部信息提取出来了。
12. 题库与文件关系不够明确，AI生成太慢，要优化，AI出的题目意义不明。
13. 做完题目没有得分统计与退出按钮。
14. 添加题目意义不明，没有导入多模态模型来识别题目，不够方便。
15. 题库点击一个时另一个会显示0道题目。
16. 搜索功能是完全匹配，应该做近义词匹配，例如大小写应该都可以。
17. 题目目前不能直接跳转刷题界面，复制与举一反三目前也没有作用，标签也没有。
18. 题库编辑功能形同虚设，无法删除题目。

## 时间线

1. 应该是大标题小标题样式，因为出题的话一次性会出很多，具体点开出题下面才是一道道题目。
2. 能否出一个撤销最近五个步骤的功能，会更加符合用户需求。
3. 不应该单独放在一个默认界面，应该是默认放在设置里面，当然也可以个性化放到状态栏与卡片上面。
4. 不应该显示所有步骤，最多显示20-50条，不然会导致无限堆积。
